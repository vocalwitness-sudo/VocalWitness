Ledger Integrity & Application-Level Immutability

Operator Transparency

Once a record is written to the Forensic Ledger or the audit log, the application and database rules make it impossible for any user (or ordinary operator) to edit or delete it.

  • Firestore security rules explicitly forbid update and delete on the ledger collections.
  • Client-side SHA-256 hashing of media and content.
  • Hash-chaining of audit entries (each entry contains the cryptographic hash of the previous one).

Important clarification: This is application-level immutability. It is not a full public blockchain. The data lives in Firebase / Google Cloud. The rules and cryptography make silent changes extremely difficult, but the ultimate trust still rests on the operator’s honesty and the cloud provider’s integrity.

External anchoring (OpenTimestamps / public chain) can be added later for extra independent proof. Application-level immutability is already active today.
