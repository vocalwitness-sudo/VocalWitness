Journalist & investigator guide

VocalWitness proves integrity (bits unchanged since sealing). It does not prove that a real-world event occurred. No account required.

Quick verification

  1. Open the shared link or QR → /verify.html?id=…&h=…
  2. Or download the Evidence Pack (JSON) from the report.
  3. Use vocalwitness.com/verify:
    • Ledger link — paste ID + hash
    • JSON proof — paste the full Evidence Pack
    • Media — drop the file (hash / C2PA if present)

Offline (command line)

  1. Download the Evidence Pack JSON and the original media.
  2. Note hashAfterUpload / media hash and bodyHash in the JSON.
  3. Hash the media yourself: 
    # Linux / macOS
sha256sum your-media-file.mp4

# Windows
certutil -hashfile your-media-file.mp4 SHA256
  4. Compare to the pack. Match = integrity OK for those bits.
