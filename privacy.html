🛡️ Architectural Data Minimization

VocalWitness is engineered so that unencrypted user identities and private device data never transit to or persist on our infrastructure. Because user identification layers are decoupled from published records via client-side processing, our system state inherently maintains no centralized identity ledger to query or disclose.

Protected by: Client-Side Zero-Knowledge Verification Automated EXIF Sanitization Edge IP Anonymization

1. Client-Bound Processing Pipeline

When media or documents are ingested, payload preparation occurs entirely within the local runtime environment prior to transmission:

  • Metadata Sanitization: EXIF data, device signatures, and geolocation tags are scrubbed in-browser.
  • Cryptographic Hashing: Files are mapped to strict cryptographic fingerprints to ensure ledger immutability.
  • Zero-Knowledge Proofs: Verification assertions are computed locally using zk-SNARK protocols to preserve user confidentiality.

2. Data Non-Retention Policy

To ensure uncompromising operational security, our systems strictly omit the collection or retention of:

  • ✕ Origin IP Addresses — network connections are terminated and stripped of identifying telemetry at the edge proxy layer.
  • ✕ Permanent Telephony Records — anti-spam verification checks are stateless and never mapped to public publication logs.
  • ✕ Government identifiers, cryptographic seed phrases, biometric profiles, or address books.

3. Permitted System State Data

Session Parameters

Pseudonymous identifiers and locally maintained cryptographic session credentials.

Ledger Artifacts

Sanitized media payloads, public cryptographic digests, and deterministic timestamps.

Integrity Tokens

Anonymous proof validation tokens used to deter automated platform abuse.

Infrastructure Metrics

Aggregated, non-attributable telemetry strictly utilized for threat mitigation.

4. Alignment with International Human Rights Standards

VocalWitness operations align directly with Articles 12 and 19 of the Universal Declaration of Human Rights, safeguarding secure communication channels, information integrity, and the fundamental right to unhindered expression.

5. Platform Neutrality & Technical Governance

VocalWitness functions strictly as an immutable technical verification layer and neutral host. The platform does not author, curate, or editorially endorse published records.

Publishing entities retain sole responsibility for the factual verification, legal compliance, and distribution context of their submissions.

6. Content Moderation & Abuse Protocols

To maintain protocol stability and protect network integrity, malicious vectors including non-consensual private media exposure, automated harassment feeds, synthetic impersonation vectors, and exploitation material are strictly prohibited.

Flagging mechanisms are available via the client interface to trigger automated review against predefined safety heuristics.

7. State Persistence & Sanitization Controls

Client state can be instantaneously purged using the Quick Exit protocol, clearing all local browser storage traces. Once an evidentiary record is committed to the public ledger, it remains cryptographically sealed and permanent.

8. Intellectual Property

The VocalWitness software architecture, user interface design, cryptographic modules, and brand assets remain the exclusive property of VocalWitness, protected under international copyright law.

⚙️ Technical & Legal Specifications

Client-Side Processing Pipeline

EXIF parameters, coordinate points, and device markers are systematically eliminated in-browser via Canvas and Web Crypto routines prior to payload transmission. Only sanitized media and SHA-256 validation strings are passed outward.

Zero-Knowledge Verification Architecture

Trust assertions are validated utilizing client-side zk-SNARK circuits, ensuring proof of validity without exposing operational or personal identity tokens. No persistent credentials reside on server nodes.

Data Exclusions

  • Origin IP logs (flushed at the Cloudflare edge network)
  • Temporary telephony validation vectors (retained strictly in volatile cache)
  • Biometric, governmental, or social network mapping artifacts

Proprietary Assets

All core protocol logic, smart contract interfaces, user interface elements, graphic branding, and system architecture are protected intellectual property.
